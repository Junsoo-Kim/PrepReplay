# 로컬 영상 분석 도구 개발 계획서

## 1. 프로젝트 개요

**목적**: 로컬에 저장된 영상 파일을 자동으로 분석하여, AI(Claude)가 이해할 수 있는 텍스트+이미지 형태로 변환하는 CLI 도구를 개발한다.

**배경**: 개발자 취업 준비 과정에서 아래와 같은 영상 자료들이 누적되는데, 이를 매번 수동으로 다시 보며 정리하기엔 시간이 많이 든다.

- 취업 컨설팅/멘토링 세션 녹화본 복기
- 채용설명회(기업 설명회, 잡페어) 녹화 영상 요약
- 기술 강의 / 부트캠프 강의 영상에서 핵심 개념 정리
- 코딩테스트/면접 스터디 녹화 복기

**핵심 아이디어**: 영상을 (1) 음성 스크립트(타임스탬프 포함)와 (2) 장면 전환 시점의 핵심 프레임 이미지로 분해하여, AI에게 "본 것처럼" 맥락을 제공한다.

---

## 2. 주요 유스케이스

| 유스케이스 | 필요 기능 | 기대 결과물 |
|---|---|---|
| 취업 컨설팅 복기 | 음성 스크립트 중심 | 컨설턴트가 짚어준 피드백/조언을 항목별로 정리, 액션아이템 추출 |
| 채용설명회 요약 | 스크립트 + 슬라이드 프레임 | 회사별 핵심 정보(연봉, 복지, 채용 프로세스, 기술스택) 구조화 요약 |
| 강의 영상 정리 | 스크립트 + 화면(코드/다이어그램) 프레임 | 개념별 타임스탬프 목차, 핵심 개념 요약, 헷갈리는 부분 재질문용 인덱스 |
| 면접/스터디 복기 | 음성 스크립트 중심 | 답변 중 약점 파악, 개선점 정리 |

→ 모든 유스케이스가 "스크립트 + 필요시 이미지" 조합으로 커버되므로, 별도 모드 분기 없이 **하나의 파이프라인**으로 처리하고, 이후 Claude에게 요청하는 프롬프트만 유스케이스별로 다르게 쓰는 방식으로 충분함.

## 3. 파이프라인 아키텍처

```
[입력: video.mp4]
      │
      ├─▶ [1] 오디오 추출 (ffmpeg)
      │         └─▶ audio.wav
      │
      ├─▶ [2] 음성 → 텍스트 (Whisper, 로컬 실행)
      │         └─▶ transcript.srt (타임스탬프 포함)
      │         └─▶ transcript.txt (순수 텍스트, 요약용)
      │
      ├─▶ [3] 장면 전환 감지 → 핵심 프레임 추출 (ffmpeg scene detection)
      │         └─▶ frames/frame_00m12s.jpg, frame_03m45s.jpg ...
      │
      └─▶ [4] 패키징 & 인덱싱
                └─▶ output/{video_name}/
                      ├── transcript.srt
                      ├── transcript.txt
                      ├── frames/
                      ├── index.md   (타임스탬프별 프레임-스크립트 매핑)
                      └── summary_prompt.md (Claude에게 바로 붙여넣을 초안 프롬프트)
```

## 4. 기능 요구사항

### 4.1 필수 기능 (MVP)
- [ ] 로컬 영상 파일(mp4, mov, mkv 등 주요 포맷) 입력 받기
- [ ] ffmpeg로 오디오 추출
- [ ] Whisper로 한국어/영어 음성 인식 (한국어 우선 최적화)
- [ ] SRT(타임스탬프 포함) + 순수 텍스트 두 가지 형식으로 스크립트 저장
- [ ] 장면 전환 감지 기반 핵심 프레임 자동 추출 (임계값 조절 가능한 옵션 제공)
- [ ] 프레임 파일명에 타임스탬프 포함 (예: `frame_00m12s.jpg`)
- [ ] 결과물을 하나의 출력 폴더로 정리
- [ ] `index.md`: "몇 분 몇 초 - 어떤 프레임 - 그 시점 스크립트 요약" 형태의 매핑 파일 자동 생성

### 4.2 편의 기능
- [ ] 긴 영상(30분 이상) 자동 구간 분할 옵션 — 구간별로 별도 요약 요청이 가능하도록 스크립트를 N분 단위로 쪼개서 저장
- [ ] `summary_prompt.md` 자동 생성 — 유스케이스별(컨설팅 복기/설명회 요약/강의 정리) 프롬프트 템플릿을 미리 채워서, 복사해서 바로 Claude에 붙여넣을 수 있게
- [ ] 처리 진행률 표시 (오디오 추출 → STT → 프레임 추출 각 단계별 진행 상황)
- [ ] 실패 시 어느 단계에서 실패했는지 명확한 에러 메시지

### 4.3 향후 확장 (선택)
- [ ] 화자 분리(diarization) — 컨설팅/스터디처럼 여러 명이 대화하는 경우 "누가 말했는지" 구분
- [ ] 여러 영상 배치 처리 (강의 시리즈 전체를 한 번에)
- [ ] 결과물을 Obsidian/노션 등 개인 지식관리 도구 포맷으로 바로 export

## 5. 기술 스택 제안

| 구성요소 | 기술 | 비고 |
|---|---|---|
| 언어 | Python 3.10+ | ffmpeg/whisper 생태계와 궁합이 좋음 |
| 오디오/프레임 추출 | ffmpeg (CLI 또는 ffmpeg-python) | 로컬 설치 필요 |
| STT | openai-whisper (로컬 실행) 또는 faster-whisper (속도 개선판) | GPU 있으면 faster-whisper 권장 |
| 장면 감지 | ffmpeg의 `select='gt(scene,X)'` 필터 | 임계값 X는 CLI 옵션으로 노출 |
| CLI 인터페이스 | argparse 또는 typer | `analyze_video.py input.mp4 --mode consulting` 같은 형태 |
| 설정 관리 | 간단한 YAML/JSON 설정 파일 (장면 감지 임계값, 언어, 구간 분할 여부 등) | |

## 6. CLI 사용 시나리오 (예시)

```bash
# 기본 실행
python analyze_video.py ~/videos/consulting_0921.mp4

# 유스케이스 지정 (요약 프롬프트 템플릿에 반영)
python analyze_video.py ~/videos/jobfair_kakao.mp4 --mode jobfair

# 긴 강의 영상, 10분 단위로 구간 분할
python analyze_video.py ~/videos/lecture_algo.mp4 --mode lecture --split 10m

# 장면 감지 민감도 조절 (기본값보다 더 촘촘하게 프레임 추출)
python analyze_video.py ~/videos/interview_practice.mp4 --scene-threshold 0.2
```

**`--mode` 옵션별 기본 프롬프트 템플릿 (summary_prompt.md에 자동 반영)**
- `consulting`: "아래는 취업 컨설팅 세션 스크립트입니다. 컨설턴트가 짚어준 피드백을 항목별로 정리하고, 실행 가능한 액션아이템 리스트를 뽑아주세요."
- `jobfair`: "아래는 채용설명회 스크립트+슬라이드입니다. 회사명, 채용 직무, 필요 기술스택, 연봉/복지, 지원 프로세스를 표로 정리해주세요."
- `lecture`: "아래는 기술 강의 스크립트+화면 캡처입니다. 핵심 개념별로 타임스탬프 목차를 만들고, 헷갈리기 쉬운 부분을 짚어주세요."

## 8. 제약사항 및 고려사항

- 로컬 실행 도구이며, claude.ai 채팅에 직접 통합되는 기능이 아님. ffmpeg, Whisper(또는 faster-whisper) 사전 설치 필요.
- Whisper 처리 속도는 하드웨어(특히 GPU 유무)에 크게 좌우됨. CPU만 있을 경우 영상 길이의 1~2배 시간 소요 예상.
- 긴 영상(1시간 이상)은 프레임 수와 스크립트 분량이 커지므로, 구간 분할 기능을 기본으로 권장.
- 개인 정보(컨설팅 세션 녹화 등)가 포함된 영상이므로, 결과물 폴더를 안전하게 로컬에만 보관하고 외부 업로드 시 주의.

## 9. 개발 마일스톤 제안

1. **1단계 (MVP)**: 오디오 추출 → Whisper STT → 스크립트 저장까지만 동작
2. **2단계**: 장면 감지 기반 프레임 추출 추가
3. **3단계**: index.md 자동 생성 + summary_prompt.md 템플릿 연동
4. **4단계**: 구간 분할, 모드별 프롬프트 템플릿 등 편의 기능
5. **5단계 (선택)**: 화자 분리, 배치 처리, 지식관리 도구 연동
